# air-agent v1.0 Release Notes

v1.0 marks the core air-agent library API as Stable.

## Stable

- Agent run loop and streaming events
- AgentConfig
- Local tools and built-in tool configuration
- MCP configuration
- Provider, Memory, and Planner protocols
- Public error hierarchy
- Tracing event model

## Experimental

- Local plugin registry
- Advanced multi-agent aggregation
- Legacy skill routers
- Future checkpoint/resume boundaries

## Compatibility Commitment

Stable API breaking changes require a major version. Experimental APIs may change in minor releases with documented migration notes.
